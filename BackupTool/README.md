# Backup Tool

## Simple file backup and restoration

A simple backup and restoration tool. Designed with the idea of being compiled into a class library, which can be loaded into [Hercules Loader](https://github.com/H0rologium/H0rologium/tree/master/HerculesLoader) as a plugin. [Read more about how to here](https://github.com/H0rologium/H0rologium/wiki/Hercules-Loader:-Adding-a-Plugin)

You can configure sets of files and/or paths that will all be compressed and copied to a chosen destination. Not currently tested with network drives.

Last built/tested on Windows 10. Requires .NET 10.
